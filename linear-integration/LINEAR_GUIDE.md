# 🚀 개발자를 위한 Linear + Git + MCP 활용 가이드

이 가이드는 Linear를 단순한 메모장이 아닌, **자동화된 개발 워크플로우**의 핵심으로 활용하는 방법을 설명합니다.

---

## 1. Linear와 Git 연동하기 (핵심 워크플로우)

개발자가 코드를 작성할 때 Linear 이슈와 Git 브랜치를 연결하면 관리 오버헤드가 사라집니다.

### 🛠 브랜치 전략
1. **이슈 번호 포함:** 브랜치를 만들 때 반드시 Linear 이슈 번호(예: `SSA-50`)를 포함하세요.
   ```bash
   # 예: SSA-50 이슈(Servlet 실습)를 처리할 때
   git checkout -b feature/SSA-50-servlet-lifecycle
   ```
2. **자동 상태 업데이트:** GitHub/GitLab 연동이 설정되어 있다면, 브랜치 푸시 시 Linear 이슈 상태가 자동으로 `In Progress`로 변경됩니다.

### 🛠 커밋 메시지로 이슈 종료
커밋 메시지에 특정 키워드를 넣으면 PR 머지 시 이슈가 자동 종료됩니다.
- `Fixes SSA-50`, `Closes SSA-54`

---

## 2. MCP (AI 에이전트) 활용법

현재 설정된 MCP를 통해 AI(Gemini)에게 다음과 같은 명령을 내릴 수 있습니다.

- **이슈 자동 생성:** "오늘 수업 들은 JSP 내용을 리니어에 추가해줘."
- **우선순위 최적화:** "내일 시험이야. 리니어 이슈들 우선순위 다시 짜줘."
- **지식 연결:** "디비 관련해서 내가 이전에 리니어에 등록했던 이슈들 요약해줘."

---

## 3. 효율적인 이슈 관리 (Triage & Cycle)

- **Triage:** 들어오는 모든 아이디어를 일단 넣으세요. 고민은 나중에 합니다.
- **Cycle:** "이번 주의 나"와 약속하는 시간입니다. 일요일 밤에 다음 주 Cycle에 할 일을 넣으세요.
- **Priority:** 
  - `P1 (Urgent)`: 오늘 당장 안 하면 큰일 나는 것 (수업 과제 등)
  - `P2 (High)`: 이번 Cycle 내에 반드시 끝낼 핵심 학습
  - `P3 (Normal)`: 시간 남을 때 볼 참고 자료

---

## 4. MCP 전용 명령어 (Gemini CLI에서 사용 가능)

Gemini CLI 환경에서 아래와 같이 요청하면 제가 대신 수행합니다.

> "리니어에서 오늘 마감인 이슈들 리스트업 해줘"
> "Spring 관련 이슈들을 'Java Backend' 프로젝트로 다 옮겨줘"
> "방금 한 Git 커밋 내용을 기반으로 리니어 이슈 상태 업데이트해줘"
